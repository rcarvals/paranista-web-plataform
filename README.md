🔗 **Acesse em produção:** [www.paranista.com.br](https://www.paranista.com.br)

---

## ⚙️ Funcionalidades Principais

* **📊 Sistema de Enquetes e Coleta de Dados:** Módulo interativo para criação de enquetes, registro de votos e persistência dos resultados em banco de dados SQL para análise de engajamento.
* **🔐 Painel Administrativo (`CMS`):** Área restrita com controle de autenticação e sessão para gestão de conteúdos, publicações e administração das enquetes sem intervenção no código.
* **🗄️ Banco de Dados Relacional (SQL):** Modelagem estruturada para armazenamento de postagens, opções de votação, registros de respostas e leads.
* **✉️ Automação de Comunicações:** Disparo automatizado de e-mails para notificações, contatos e confirmações integrados ao servidor.
* **📱 Experiência do Usuário (UI/UX):** Interface responsiva otimizada para leitura fluida, navegação rápida e alta taxa de interação em dispositivos móveis.

---

## 🛡️ Arquitetura e Boas Práticas

* **Operações Completas (`CRUD`):** Ciclo completo de criação, leitura, atualização e exclusão de registros diretamente pela interface administrativa.
* **Segurança e Integridade:** Validação de entradas de formulários, proteção de rotas administrativas e isolamento de credenciais de acesso ao banco de dados.
* **Arquitetura Modular:** Organização clara entre regras de processamento back-end, consultas SQL e templates visuais.
